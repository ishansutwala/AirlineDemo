# Provenance and permitted use

| Material | Classification | Origin | Limits |
|---|---|---|---|
| Airport facts | PUBLIC_REFERENCE | S04 and row-level airport URLs | Community dataset; not for navigation; timezone mapping assigned separately |
| Published EK43/EK44 route times | PUBLIC_REFERENCE_SNAPSHOT | S02 | No same-tail allocation, dated booking or live status verified |
| All operational database records | SYNTHETIC | Reproducible generator, seed 21743 | No actual airline maintenance, people, stock, prices or ground-time data |
| Knowledge PDFs / Markdown | SYNTHETIC_NOT_FOR_MAINTENANCE | Original planning fixtures | Not OEM manuals, actual MEL entries or physical maintenance instructions |
| Model weights | NOT_INCLUDED | Install from approved upstream source | License/digest/evaluation required before use |
| Reference-mode results | EXECUTED_DETERMINISTIC_DEMO | Local application tests and HTTP smoke test | Not evidence of SLM accuracy or real operational benefit |

Public full-text manuals and proprietary airline records are intentionally not redistributed. Realistic field structures and constraints are implemented without claiming access to confidential operational systems. See source_register.json and data/seed/sources.csv for citations and limits.
